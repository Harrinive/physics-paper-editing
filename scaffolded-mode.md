# Scaffolded economy mode

Use this file only when the editor is `economy` or `unknown`. The scaffold makes
the reasoning explicit without asking a weaker model to settle ambiguous
physics.

Repeat the object row for each new or materially changed story-bearing object.
Omit the math block only when no formal content changes. Complete every
applicable canon check even though the worksheet records only failures.

## Boundaries

An economy editor may:

- tighten local wording;
- split or join sentences without changing the argument;
- fill the worksheet from explicit context;
- apply a repair already selected by a capable reviewer;
- identify competing interpretations and escalate them.

It must not:

- choose between scientifically distinct meanings without evidence;
- invent an operational criterion or equivalence;
- treat a helper as justified merely because it shortens one formula;
- adjudicate a changed derivation or strong claim without capable review.

For reviewed work, pass the worksheet and candidate to the mandatory sentence
and terminology-and-notation reviewers, then to the triggered specialists and holistic
reviewer. For high-risk work, use capable blind physics and formal reviewers;
retain the economy model only for bounded preparation or local repair.
