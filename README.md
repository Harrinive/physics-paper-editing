# Physics paper editing skill

The active workflow is version 2: physics-first object choice with adaptive
verification for short LaTeX, Markdown, or plain-text physics passages. Every
path enforces the full applicable canon; direct editing reduces orchestration,
not quality coverage. Start with [SKILL.md](SKILL.md).

Version-1 jobs are closed historical records. New and repeated work uses a
fresh version-2 job with explicit selective or exhaustive language coverage and
current source snapshots.
