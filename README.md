# Physics paper editing skill

The active workflow is version 2: physics-first object choice with direct or
reviewed editing for short LaTeX, Markdown, or plain-text physics passages.
Reviewed work always includes sentence and terminology checks, independently
when the host and user permit, and adds principle, physics, or formal
specialists when triggered. Every path enforces the full applicable canon.
Start with [SKILL.md](SKILL.md).

Version-1 jobs are closed historical records. New and repeated work uses fresh
version-2 checks with explicit selective or exhaustive language coverage.
Snapshots and persisted state are created only when the work is resumable,
asynchronous, concurrent, file-based, or exhaustive.
